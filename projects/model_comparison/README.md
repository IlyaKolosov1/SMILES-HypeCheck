# Проект: модели и их сочетания

Сравниваем FM с классическими uplift-моделями и meta-learners, затем проверяем смешение и совместный эффект со стратегией выбора контекста. Для нового сравнения нужны общие train/eval-объекты, outcome и заранее выбранная метрика.

| Гипотеза | Статус |
| --- | --- |
| [M01: FM против baseline](hypotheses/M01/README.md) | Только старый Hillstrom notebook-пилот; общий benchmark запланирован |
| [M02: смешение](hypotheses/M02/README.md) | План, реализации и результатов нет |
| [M03: контекст + смешение](hypotheses/M03/README.md) | План, реализации и результатов нет |
| [M04: PEHE и targeting](hypotheses/M04/README.md) | Исторический синтетический отчёт, отдельного CSV не было |

Старый notebook сохранён в [src](src/), его отчёт — внутри M01. Эксперименты этого проекта не следует объединять с таблицами выбора контекста без общего протокола. Правила оформления результата — в [корневом руководстве](../../docs/EXPERIMENTS.md).
