# M01 / E04 / v001 — локальный baseline на сохранённых Criteo-когортах

- **Статус:** plan. Протокол зафиксирован до вычисления прямого локального uplift на Criteo. FM-результаты этих когорт уже просмотрены в CS01/E03, поэтому E04 — **повторный разведочный анализ**, не независимое подтверждение.
- **Вопрос:** даёт ли CausalPFN с feature-контекстом преимущество над простым средним treatment effect по **тем же** соседям на втором реальном источнике, Criteo?
- **Источник:** только завершённый снимок [CS01/E03/v001](../../../../../context_selection/hypotheses/CS01/experiments/E03/v001.md) `20261018T201230_193386Z` с тремя непересекающимися sample seeds `401–403`. Использовать его записанные локальные пути, `train_rows.csv`, `eval_rows.csv`, `predictions.csv`, `context_rows_feature_knn_K512.npy`; не запускать CausalPFN снова. Исходные данные: Criteo-ITE-v2.1, `T`, benefit outcome `visit`, SHA из CS01/E03. При несовпадении файлов или строк остановить анализ.
- **Локальный baseline:** для каждой eval-строки взять средний train-`visit` среди 256 treated минус средний среди 256 control в **сохранённом** feature-контексте. Не сглаживать, не подбирать гиперпараметры и не использовать eval-исход при формировании score. Для точного соответствия `source_row → T/visit` один раз прочитать объединение трёх train/eval наборов из исходных parquet и сверить labels и context IDs.
- **Primary:** Q̂ (`normalized_qini_auc`), парная разность `CausalPFN feature_knn_K512 − local_feature_mean` в каждой из трёх Criteo-когорт. Показать равновесное среднее и число положительных когорт. Заранее заданный **описательный ориентир**: средняя разность > 0 и 3/3 когорт положительны. Невыполнение сузит наблюдение о добавочной ценности FM до LZD.
- **Secondary:** абсолютные Q̂, normalized AUUC, uplift@10%; сравнение CausalPFN с фиксированным X-Learner из CS01/E03 оставлять отдельным и не подменять им primary. Для primary посчитать 500 парных bootstrap повторов eval-строк внутри treatment arms, seeds `951–953`; интервалы условны на готовых score и каждой когорте. Три когорты взяты из одного Criteo источника, общий p-value и независимую значимость не заявлять.
- **Хранение:** новые локальные score и сверки — в `artifacts/local/m01_e04_results/`; компактный неизменяемый снимок с протоколом, метриками, SHA входов/выходов и кода — в `results/E04/v001/<run-id>/`. Все старые результаты остаются нетронутыми.

Из корня репозитория `.venv/bin/python -u tools/run_m01_e04.py --check` проверяет SHA, source IDs, labels и составы контекстов без расчёта baseline; та же команда без `--check` вычисляет локальный baseline и упаковывает результат. После выполнения независимо пересчитать локальный score и Q̂, проверить ссылки и валидатор репозитория.
