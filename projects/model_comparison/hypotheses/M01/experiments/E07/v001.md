# M01 / E07 / v001 — ретроспективный S/T-контроль для Criteo E06

- **Статус:** plan для воспроизводимого post-hoc анализа. Когорты `404–406`, их FM/X/local Q̂ и uplift@10% уже просмотрены в [M01/E06](../E06/v001.md). Этот анализ не является новой проверкой гипотезы и не меняет E06 primary.
- **Вопрос:** выдерживает ли замеченное после E06 преимущество FM по uplift@10% сравнение с фиксированными S- и T-Learner на тех же строках?
- **Источник:** неизменяемый снимок M01/E06/v001 `20261019T125852_487521Z`, его локальные `sample_rows`, `train_rows`, `eval_rows` и предсказания, те же SHA Criteo parquet. Сверить все SHA, source IDs, treatment/outcome и отсутствие train/eval пересечений. Новые данные и CausalPFN-инференс не использовать.
- **Модели:** обучить S-Learner и T-Learner из `m01_e02.fit_predict` на тех же 51 200 train-строках каждой когорты, с параметрами `learning_rate=0.05`, `max_iter=200`, `max_leaf_nodes=31`, `l2_regularization=1.0`, `random_state=42`; использовать train-only preprocessing. Функция также вычисляет X-Learner: сверить его score с сохранённым E06 в пределах численной точности. Это фиксированные конфигурации, подбор по eval запрещён.
- **Метрики:** Q̂, normalized AUUC, uplift@10% при том же стабильном порядке ties, что E06, для FM, S/T/X и локального среднего. Показать парные разности FM−S и FM−T по когортам и число положительных когорт. 500 парных stratified bootstrap-повторов по eval-строкам внутри когорты, seeds `9700+sample_seed`, только условные интервалы.
- **Ограничение:** все сравнения и выбор uplift@10% сделаны **после** просмотра E06. Даже устойчивое направление служит лишь выбору следующего baseline, не статистическим подтверждением.
- **Хранение:** полные новые score в `artifacts/local/m01_e07_results/`; один компактный неизменяемый снимок `results/E07/v001/<run-id>/` с метриками, интервалами, source/local SHA, Git SHA и SHA кода. Старые снимки не менять.

Перед расчётом проверить `.venv/bin/python tools/run_m01_e07.py --check`, `--help`, валидатор и зафиксировать код/протокол в Git. Затем `.venv/bin/python -u tools/run_m01_e07.py` вычислит и упакует результат; после завершения пересчитать метрики независимо.
