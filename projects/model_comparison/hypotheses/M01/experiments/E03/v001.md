# M01 / E03 / v001 — вклад FM сверх локального uplift на новых LZD когортах

- **Статус:** plan. Протокол записан во время расчёта CS01/E05, до получения его Q̂. Вопрос возник после разведочного повторного анализа уже просмотренного E04: на его LZD holdout прямое среднее по feature-контексту дало Q̂ `0.0503`, CausalPFN с тем же контекстом — `0.0812`. E04 не служит независимым подтверждением этого контраста.
- **Вопрос:** добавляет ли CausalPFN качество uplift-ранжирования сверх простого локального оценивателя на **тех же** подобранных примерах? Как этот вариант FM соотносится с фиксированными S/T/X-Learner на тех же train/eval строках?
- **Источник:** только три завершённые когорты [CS01/E05/v001](../../../../../context_selection/hypotheses/CS01/experiments/E05/v001.md): отдельные LZD train banks по 51 200 и eval-наборы по 8192 строк, предсказания `feature_knn_K512`, сохранённые context IDs, `T` и benefit outcome `Y`. При `incomplete` E05 не вычислять и не заменять когорту. Перед обучением сверять SHA LZD parquet/metadata, код/manifest E05, полный порядок `source_row`, `T/Y`, отсутствие пересечений train/eval и состав каждого контекста (256 control + 256 treated).
- **Локальный baseline:** для каждого eval-объекта из **сохранённого feature-контекста E05** взять среднее train-исхода `Y` среди 256 treated минус среднее среди 256 control. Никакого сглаживания, подбора веса или использования eval-исходов при построении score. Это эмпирический локальный uplift, а не известный истинный CATE.
- **Классические baselines:** S-, T- и X-Learner из M01/E02 с `HistGradientBoostingClassifier` для исхода и `HistGradientBoostingRegressor` для второго этапа X-Learner. `learning_rate=0.05`, `max_iter=200`, `max_leaf_nodes=31`, `l2_regularization=1.0`, seed `42`; train-only preprocessing, без подбора по eval. Все методы обучаются или формируют score на тех же строках соответствующей E05 когорты.
- **Primary:** Q̂ (`normalized_qini_auc`), разность `CausalPFN feature_knn_K512 − local_feature_mean` внутри каждой когорты. Равновесное среднее трёх разностей и число положительных когорт. Заранее заданный **описательный ориентир:** средняя разность > 0 и 3/3 когорты положительны. Невыполнение означает, что вклад FM сверх этого локального baseline данным протоколом не подтверждён.
- **Secondary:** абсолютные Q̂ всех пяти методов, разности FM с каждым S/T/X-Learner, normalized AUUC, uplift@10%. Для четырёх парных Q̂-контрастов посчитать по 500 bootstrap повторов eval-строк внутри каждого treatment arm, seeds `941–943`. Интервалы условны на готовых scores и данной когорте. Три когорты происходят из одного RCT источника LZD; обычный t-test или заявление о значимости общего эффекта не делать. «Лучший» классический метод по eval не выбирать.
- **Хранение:** полный набор новых классических и локальных scores — в `artifacts/local/m01_e03_results/`; компактный неизменяемый результат с протоколом, таблицами, SHA источников и кода — внутри `results/E03/v001/<run-id>/`. CausalPFN повторно не запускать. При ошибке сохранить `incomplete`, не подменять заранее заданные когорты.

После завершения E05 выполнить `.venv/bin/python -u tools/run_m01_e03.py --source artifacts/local/cs01_e05_results/<run-id> --check` для проверки входов без обучения; та же команда без `--check` считает baselines и упаковывает результат. `--source` должен указывать завершённый E05 run со снимком, а при нескольких запусках путь выбирается явно. Затем независимо пересчитать Q̂ и проверить валидатор репозитория. Итоговая интерпретация должна явно отделять выигрыш **выбора соседей** от дополнительного вклада **CausalPFN**.
