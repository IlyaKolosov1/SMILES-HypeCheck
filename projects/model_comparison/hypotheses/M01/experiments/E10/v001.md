# M01 / E10 / v001 — фиксированная смесь локального и глобального рангов

- **Статус:** plan; явно post-hoc анализ. Исходы и метрики шести Criteo-когорт `407–412` уже просмотрены в M01/E08 и CS05/E01. Состав двух моделей выбран после этих результатов, поэтому даже положительный итог не подтверждает гипотезу. Owner: участники M01; независимая проверка ожидается.
- **Вопрос:** дополняют ли друг друга прямой treatment-balanced local feature-kNN и глобальный S-Learner при одинаковых train/eval строках? Их ранжирования на CS05-когортах имеют умеренную Spearman-корреляцию; это мотивирует один фиксированный тест без подбора веса.
- **Источник:** неизменяемые снимки M01/E08/v001 `20261019T141726_397774Z` (когорты `407–409`) и CS05/E01/v001 `20261019T172329_275728Z` (`410–412`), их `predictions.csv`, `sample_rows`, протоколы и SHA. В каждой когорте 51 200 train и 32 768 eval, outcome `visit`, `K=512`. Сверить хеши, соответствие `source_row/T/Y`, отсутствие повторов и непересечение шести исходных выборок. Ничего не переобучать, CausalPFN не запускать и не менять старые снимки.
- **Метод:** отдельно в каждой когорте преобразовать `local_feature_mean` (E08) либо `local_feature_knn_K512` (CS05) и `s_learner` в процентильные ранги на **всех eval-score без использования T/Y**, с `scipy.stats.rankdata(method="average") / n`. Score смеси — арифметическое среднее двух рангов с весами **0,5/0,5**, без подгонки, нормировки по исходам или выбора весов по когорте. Сравнить с исходными двумя score на тех же eval-строках; ранги для baseline отдельно не переопределяют их Q̂.
- **Primary описательные сравнения:** Q̂ (`normalized_qini_auc`) смеси минус Q̂ прямого локального метода и минус Q̂ S-Learner внутри каждой когорты. Показать шесть разностей, их равновесные средние и число положительных когорт. Единственный **ориентир для решения о новом тесте**, не критерий статистического подтверждения: обе средние положительны, обе разности положительны минимум в 4/6 когорт, нижние границы 95% условного bootstrap-интервала средних > 0. При невыполнении не подбирать другие веса на этих eval.
- **Неопределённость:** 500 парных bootstrap-повторов eval-строк внутри treatment arms с фиксированными score, seeds `11000+sample_seed`. Одинаковые resampled rows для всех трёх методов; интервалы средних из равновесного среднего draws по шести когортам. Интервалы условны на обученных моделях, самих когортных split и post-hoc выборе смеси; когорты происходят из одного Criteo-источника и не являются независимыми датасетами.
- **Secondary:** абсолютные Q̂, normalized AUUC, uplift@10% с предзаданным hash-порядком ties по `source_row` из M01/E08. Вторичные метрики не меняют primary; успешность по uplift@10% отдельно не объявлять.
- **Хранение:** полный score смеси — только `artifacts/local/m01_e10_results/`. Один компактный неизменяемый снимок `results/E10/v001/<run-id>/` с метриками, разностями, условными интервалами, SHA входов и выхода, Git SHA и SHA кода.

Перед расчётом проверить `.venv/bin/python tools/run_m01_e10.py --help`, `--check`, `--smoke`, валидатор и зафиксировать код/протокол Git-коммитом. Затем `.venv/bin/python -u tools/run_m01_e10.py all`; после результата независимо сверить ранги, метрики и bootstrap. Новый prospective тест проектировать только по этому неизменённому правилу и на не просмотренных строках.
