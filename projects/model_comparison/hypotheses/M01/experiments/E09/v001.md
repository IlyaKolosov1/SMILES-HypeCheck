# M01 / E09 / v001 — разложение эффекта выбора контекста

- **Статус:** plan; ретроспективный анализ. Метрики CausalPFN из CS01/E02, а также более поздние сравнения FM с локальным средним и классическими моделями уже известны. Здесь нельзя заявлять независимое подтверждение или выбирать удачный датасет после расчёта. Owner: участники M01; независимая проверка результата ожидается.
- **Вопрос:** является ли прирост Q̂ от feature-kNN против случайного query-контекста специфичным для CausalPFN или его воспроизводит прямое среднее исходов по тем же соседям? Это проверка механизма после отрицательного M01/E08, не попытка заменить его primary.
- **Источник:** неизменяемый CS01/E02/v001 `20261017T170010_816255Z`, четыре датасета Hillstrom, Retailhero-uplift, LZD, Criteo-ITE-v2.1 и split seeds `101–103`. На каждом split использовать только сохранённые 51 200 train IDs, 4096 eval IDs, предсказания FM и context IDs `feature_knn_K512`, `random_query_s201_K512`, `random_query_s202_K512`, `random_query_s203_K512`. Criteo source samples `301–303` соответствуют split. Исходные parquet, пять хешированных входных файлов на сочетание dataset × split, treatment и outcome сверить до расчёта. Context IDs хешировать в новом результате: они не входили в старый `source_files.csv`.
- **Методы:** FM-score читать из CS01/E02 без нового инференса. Для каждого сохранённого контекста вычислить прямой local-score: среднее train-benefit среди 256 treated минус среднее среди 256 controls. Никакой подгонки по eval и никакого нового отбора соседей. Проверить ровно 512 различных train IDs, баланс 256/256, отсутствие train/eval пересечения, соответствие eval `T/Y` исходным parquet и сохранённым predictions. Для Hillstrom outcome `visit`, для остальных — `Y`, кроме Criteo `visit`.
- **Primary описательные величины:** Q̂ (`normalized_qini_auc` из `qini_auc_score`). Внутри dataset × split сначала усреднить **метрики** трёх random-context seeds отдельно для FM и local; затем показать `FM feature − FM random mean`, `local feature − local random mean`, их interaction `(FM gain − local gain)` и `FM feature − local feature`. Сводка — равновесное среднее трёх split и число положительных split по каждому датасету. Seeds контекста не считать независимыми повторениями; разбиения одного датасета пересекаются.
- **Неопределённость:** 300 парных bootstrap-повторов eval-строк внутри treatment arms для каждой из четырёх разностей, с фиксированными score и seed `9900 + split_seed + dataset_index × 10`. С одинаковыми resampled rows для FM/local/context вариантов. Интервалы условны на выбранных данных, моделях и post-hoc постановке; **p-value и правило успеха не задавать**. Если метрика неопределена в draw, сохранить число валидных повторов и не подменять seed.
- **Secondary:** абсолютные Q̂, normalized AUUC, uplift@10% с единым детерминированным разрешением ties по `source_row` как в M01/E08. Эти показатели описательные и не меняют primary. Для сравнения методов используется один outcome и одни eval-строки внутри split.
- **Хранение:** производные per-row local-score и контексты остаются в `artifacts/local/`. Один компактный неизменяемый снимок `results/E09/v001/<run-id>/`: протокол, Q̂/AUUC/uplift@10%, парные разности и условные интервалы, сводка по датасетам, SHA входов и выхода, Git SHA и SHA кода. Старые CS01/M01 результаты не менять.

Проверить `--help`, `.venv/bin/python tools/run_m01_e09.py --check` и валидатор; зафиксировать код и протокол до расчёта производных local-score. Затем `.venv/bin/python -u tools/run_m01_e09.py all`. Полного FM-инференса здесь нет. По результату выбрать **одну** конкретную гипотезу для будущих новых данных, не трактуя этот разбор как подтверждение.
