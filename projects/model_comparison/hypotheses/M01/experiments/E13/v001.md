# M01 / E13 / v001 — внешний контроль на IHDP

- **Статус:** plan. Код и протокол фиксируются коммитом до расчёта метрик. Owner: команда M01.
- **Вопрос:** переносится ли наблюдение M01/E12 о меньшей ошибке CATE у CausalPFN относительно прямого локального среднего по **тем же** соседям на другую семью полусинтетических данных? ACIC и IHDP различаются covariates, механизмом генерации outcome и объёмом train; здесь не проверяется универсальное превосходство FM над всеми моделями.
- **Источник:** оригинальные [IHDP train/test NPZ](https://www.fredjo.com/files/) из линии `clinicalml/cfrnet`, описание и фиксированные SHA приведены в [загрузчике CausalML](https://causalml.readthedocs.io/en/latest/_modules/causalml/dataset/_benchmarks.html). Файлы `ihdp_npci_1-100.train.npz` и `.test.npz` локально в `artifacts/local/external/ihdp/`, в Git не входят. Использовать все 100 репликаций, официальный split каждой: 672 train и 75 test; 25 covariates. Моделям доступны только train `x,t,yf` и test `x`; `mu0/mu1` только для оценки, `ycf` и test `yf` не использовать. Истинный CATE = `mu1−mu0`.
- **Контекст и модели:** из-за 117–131 treated на train бюджет `K=128`, 64 control и 64 treated. Feature-kNN отдельно по arms и query-dependent random с seeds `41,42,43`; одинаковые train/test строки, преобразованные признаки и контексты для FM и прямого локального среднего. CausalPFN checkpoint `83aad07da1cb077cfda4236878a1b07dc9f72a54`, CPU. T-Learner — два `HistGradientBoostingRegressor` с `learning_rate=0.05`, `max_iter=200`, `max_leaf_nodes=31`, `l2_regularization=1.0`, `random_state=42`. Преобразования признаков обучать только на train; параметры по test не выбирать.
- **Primary:** PEHE = RMSE score относительно `mu1−mu0` на официальном test. Разность `PEHE(local feature)−PEHE(FM feature)` делить на SD **фактического train-outcome** каждой репликации для сравнения масштабов. Предзаданный описательный ориентир: положительная разность минимум в 70/100 репликаций, её среднее нормированное значение больше `0.1`, нижняя граница условного 95% bootstrap-интервала среднего больше нуля. Все репликации показывать; не выбирать лучшие по test.
- **Secondary:** FM против фиксированного T-Learner по той же нормированной PEHE; feature против среднего **метрик** трёх random-контекстов у FM и local, их interaction; oracle regret@10%; абсолютные PEHE. Положительный знак разностей PEHE означает меньшую ошибку FM или лучшего feature-retrieval. Не переносить решение о primary на secondary после просмотра результатов.
- **Неопределённость и ограничения:** 300 общих bootstrap-ресемплов 75 test-строк внутри каждой репликации, seeds `15000+replication` для нумерации `0–99`; усреднение одноимённых draw по 100 репликациям даёт только **условный** интервал. Репликации используют одних исходных детей, а test мал; нельзя трактовать их как 100 независимых исследований или делать утверждение о значимости между источниками. ACIC-результат уже просмотрен, поэтому IHDP — заранее заданный внешний контроль для этой узкой гипотезы, не новое рандомизированное исследование.
- **Хранение:** полные score, truth и контексты — `artifacts/local/m01_e13_results/` вне Git. Один неизменяемый снимок `results/E13/v001/<run-id>/` с метриками, парными разностями, хешами входов/выходов, Git и SHA кода. При сбое репликация получает `incomplete` и не заменяется другой. Старые результаты не менять.

Команды из корня: `.venv/bin/python tools/run_m01_e13.py --check` проверяет оба файла, все 100 split и checkpoint; `.venv/bin/python tools/run_m01_e13.py --smoke` выполняет два FM-запроса без оценки test; `.venv/bin/python -u tools/run_m01_e13.py all` считает 100 репликаций и упаковывает снимок; `.venv/bin/python tools/run_m01_e13.py --status` показывает сохранённые стадии.
