# M02 / E01 / v001 — проект протокола смеси

Для первой версии использовать score `α·FM + (1−α)·classic` при одинаковом outcome и test IDs. Выбрать классическую модель, нормализацию score, сетку `α` и primary метрику **на train/validation**, не по test outcomes. На test сравнить FM, classic и смесь парно; сохранить OOF/validation процедуру настройки, checkpoint и split IDs. Статистический вывод строить по заранее выбранному primary контрасту, не по лучшему из множества просмотренных весов.

Статус: **план**. Пока нет кода, выбранной модели/сетки и результатов; перед запуском оформить их новой неизменяемой версией протокола.
