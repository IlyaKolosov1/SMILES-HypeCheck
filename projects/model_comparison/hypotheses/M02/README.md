# M02 — смешение FM и классической модели

**Гипотеза:** заранее настроенная смесь CausalPFN и классического uplift learner может улучшить targeting относительно обоих компонентов. Primary контраст — смесь против лучшего отдельного компонента на тех же eval-строках; primary метрику и правило множественных сравнений нужно зафиксировать до запуска.

[E01/v001](experiments/E01/v001.md) — проект протокола с настройкой веса на train/validation. [E01/v002](experiments/E01/v002.md) — завершённый разведочный пилот фиксированной смеси 50/50 по сохранённым предсказаниям CS01 и M01. [Снимок результатов](results/E01/v002/20261018T162058_653667Z/README.md) показывал описательный сигнал для пары feature-kNN + X-Learner на Criteo. На [новых Criteo-строках M03/E02](../M03/results/E02/v001/20261018T210533_998627Z/README.md) смесь уступила feature-kNN в среднем на `0.0219` Q̂; гипотеза о стабильном выигрыше смеси сверх обоих компонентов не подтвердилась.
