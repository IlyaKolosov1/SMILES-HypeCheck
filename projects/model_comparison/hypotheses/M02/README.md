# M02 — смешение FM и классической модели

**Гипотеза:** заранее настроенная смесь CausalPFN и классического uplift learner может улучшить targeting относительно обоих компонентов. Primary контраст — смесь против лучшего отдельного компонента на тех же eval-строках; primary метрику и правило множественных сравнений нужно зафиксировать до запуска.

[E01/v001](experiments/E01/v001.md) — проект протокола с настройкой веса на train/validation. [E01/v002](experiments/E01/v002.md) — завершённый разведочный пилот фиксированной смеси 50/50 по сохранённым предсказаниям CS01 и M01. [Снимок результатов](results/E01/v002/20261018T162058_653667Z/README.md) показывает описательный сигнал для пары feature-kNN + X-Learner на Criteo; независимого подтверждения гипотезы пока нет.
