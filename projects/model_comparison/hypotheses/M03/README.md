# M03 — совместный эффект контекста и смешения

**Гипотеза:** сочетание выбранного контекста и смеси FM с классической моделью даёт выигрыш сверх каждого компонента. Сравнение должно отделять вклад selector от вклада смеси и проверить их взаимодействие на одинаковых eval-строках.

[E01/v001](experiments/E01/v001.md) — исходный проект 2×2 протокола. [E01/v002](experiments/E01/v002.md) — завершённый разведочный анализ с X-Learner по сохранённым предсказаниям. [Снимок результата](results/E01/v002/20261018T163258_462386Z/README.md): положительный interaction не обнаружен; на Criteo смесь 50/50 ослабила разность feature-контекста с random с `+0.1616` до `+0.0902` Q̂ (среднее по трём split). Эффект требует проверки на новых данных.

[E02/v001](experiments/E02/v001.md) проверил отрицательное interaction на трёх новых непересекающихся Criteo-выборках без повторного инференса FM. [Снимок результата](results/E02/v001/20261018T210533_998627Z/README.md): среднее interaction `−0.0441` Q̂, отрицательно в 3/3 выборках. Однако смесь 50/50 уступила feature-kNN в среднем на `0.0219` Q̂ и превзошла его только в 1/3. Основной позитивный сигнал здесь относится к выбору контекста; гипотеза о выигрыше смеси сверх обоих компонентов на этих строках не подтвердилась.
