## Вывод и границы

На этом заранее зафиксированном внешнем RCT механистический результат E02 **не перешёл в подтверждённое преимущество таргетинга**. Малый положительный AIPW point estimate не является доказательством выигрыша; интервал не доказывает и эквивалентность моделей. Признаки, гиперпараметры и бюджет не подбирались под eval. Это один обработанный срез кампании и один split; bootstrap условен на обученных score, возможны spillovers между соседями. Оценён эффект назначения письма, а не его прочтения.
