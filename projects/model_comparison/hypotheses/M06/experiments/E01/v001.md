# M06/E01/v001 — oracle-разложение локальной ошибки

**Статус:** retrospective exploratory. Этот анализ сформулирован после просмотра ACIC, IHDP и M05; порога подтверждения нет. Owner: команда M06.

## Данные и расчёт

Использовать только неизменённые локальные предсказания [M01/E12](../../../M01/experiments/E12/v001.md), [M01/E13](../../../M01/experiments/E13/v001.md) и [M05/E01](../../../M05/experiments/E01/v001.md), а также проверенные исходные ACIC/IHDP и M05 `base.npz`. Для каждой query и выбранного контекста определить:

- `local`: среднее наблюдаемых train-outcome treated минус такое же среднее control;
- `oracle_local`: те же индексы, но вместо наблюдаемых исходов подставлены истинные условные средние `mu1` и `mu0` train-строк;
- `FM`: сохранённый CausalPFN score; `truth`: истинный CATE eval-строки.

`oracle_local` устраняет случайный шум train-outcome, но **не** отличие контекстных train-строк от query. Считать RMSE `local`, `oracle_local`, `local−oracle_local` и `FM` относительно `truth`, а также внутри случая корреляцию `FM−local` с `truth−oracle_local`. Для ACIC: восемь неоднородных сценариев и feature плюс три random-контекста. Для IHDP: 100 репликаций и те же четыре типа контекста. Для M05: восемь бинарных генераций, только feature-контекст. Среднее трёх random считать **внутри случая**; реплики и сценарии одной семьи не объявлять независимыми источниками.

Исходные массивы не менять. Компактный снимок должен содержать все значения по случаям, сводку, SHA исходных файлов, SHA скрипта и Git SHA. Полные score остаются в `artifacts/local/`.

## Интерпретация

Этот анализ показывает, какую часть ошибки прямого локального оценивателя можно объяснить геометрией уже выбранного контекста, и совпадает ли направление поправки FM с требуемым направлением. Он не доказывает, что FM распознала именно эту величину: истинный CATE участвует в диагностике, а семейства DGP и размер eval различаются. Проверка на независимом контролируемом вмешательстве в контекст и практической policy-метрике необходима до заявления для статьи.

Расчёт из корня репозитория: `.venv/bin/python tools/analyze_m06_e01.py`. Код читает архивы, но не выполняет FM-инференс.
