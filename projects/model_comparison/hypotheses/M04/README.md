# M04 — CATE-оценка против targeting

**Вопрос:** может ли модель с меньшей ошибкой CATE иметь худшее ранжирование для ограниченного бюджета воздействия? PEHE/CATE RMSE требуют известного истинного CATE; на реальном Hillstrom их нет.

[E01/v001](experiments/E01/v001.md) и [историческая запись](results/E01/v001/notebook-synthetic-pilot/) описывают только синтетический notebook-пилот. Отдельного CSV не было, а расхождение PEHE и targeting он не подтвердил. Новый тест этой гипотезы требует отдельного DGP или других наборов с известным CATE и нового протокола.
