# Исходники исторических запусков

Эти файлы сохранены побайтно **до переноса и исправления путей**. Имя содержит SHA-256 содержимого. Они нужны для проверки `script_sha256` в старых протоколах, а не для новых запусков. Актуальные скрипты находятся в [src](../src/).

Для cross-dataset v002/v003, synthetic retrieval и ABC SHA совпадает с записанным в их конфигурациях. Точный исходник cross-dataset v001 в исходном checkout отсутствовал; его исторический SHA известен только из протокола.
