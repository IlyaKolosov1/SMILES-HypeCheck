# CS04 / E03 / v001 — ретроспективная проверка model × context

- **Статус:** post-hoc exploratory. Контраст выбран **после просмотра** CS04/E01 и предварительного расчёта локального среднего по его сохранённым контекстам. Это воспроизводимая диагностика, а не заранее заданное подтверждение.
- **Источник:** только завершённый [CS04/E01/v001](../E01/v001.md), run `20261019T064211_090052Z`, seeds `61–70`. Проверить manifest, SHA компактных и локальных файлов, парность данных и контекстов; CausalPFN не запускать вновь.
- **Вопрос:** меняет ли выбор соседей между `feature_knn_d8` и `feature_knn_d32` CATE RMSE **по-разному** для CausalPFN и простого среднего uplift по тем же treatment-balanced контекстам?
- **Локальный score:** для каждой eval-строки средний бинарный `Y_train` по 256 treated соседям минус средний по 256 control соседям. Ни подбора, ни сглаживания, ни использования eval outcomes для score. Использовать E01 train labels, context IDs и true eval CATE для оценки.
- **Контрасты:** `D_local = RMSE(local_mean_feature32) − RMSE(local_mean_feature8)` и `D_FM = RMSE(PFN_feature32) − RMSE(PFN_feature8)` при том же 32-мерном входе FM. Диагностическое взаимодействие `I = D_FM − D_local`; отрицательное `I` означает, что переход к feature32 помогает FM относительно локального среднего. Показать все десять пар и абсолютные RMSE каждого метода; не формулировать post-hoc порог успеха.
- **Дополнительно:** Q̂ по observed eval `Y/T`, истинный regret@10%, средняя и число seeds по каждому контрасту. Отдельно показать, выигрывает ли FM у direct local mean в абсолютной CATE RMSE. Условный bootstrap среднего по 10 generated datasets (10 000 resamples, seed `985`) описывает разброс именно этого DGP; выбранный после просмотра контраст и множественность поиска не позволяют использовать его как подтверждающий p-value.
- **Хранение:** локальные таблицы и скопированные проверенные исходные ссылки — в `artifacts/local/cs04_e03_results/`; компактный неизменяемый снимок с Git/code SHA, source SHA, протоколом и ограничениями — в `results/E03/v001/<run-id>/`. E01 не менять.

Перед публикацией независимо пересчитать direct scores и CATE RMSE из сохранённых `data.npz` и `context_*.npy`, сверить значения FM с E01 и запустить валидатор репозитория.
