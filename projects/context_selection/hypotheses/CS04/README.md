# CS04 — когда локальный контекст перестаёт помогать

**Вопрос:** зависит ли выигрыш treatment-balanced feature-kNN контекста для CausalPFN от того, насколько расстояние в признаках отражает близость истинного эффекта лечения?

Статус: **разведочный результат**. [E01/v001](experiments/E01/v001.md) проверил синтетический DGP с известным CATE: к той же задаче добавлены 24 нерелевантных признака, а исходы и treatment идентичны внутри парного seed. Основной контраст сравнивает выбор соседей по 8 полезным или по всем 32 признакам **при одном входе FM из 32 признаков**. [Компактный результат](results/E01/v001/20261019T064211_090052Z/README.md) содержит все 10 генераций, предсказания и контексты остались в `artifacts/local/`.

Предзаданный ориентир **не выполнен**: `RMSE(feature32) − RMSE(feature8) = −0.01251` в среднем, отрицателен в 10/10 генераций; bootstrap-интервал по generated seeds `[−0.01531; −0.00980]`, двусторонний sign-test `p=0.00195` **в пределах этого DGP**. При этом feature8 выбирает соседей с меньшим средним расхождением по истинному CATE (`0.0492` против `0.0687`). Следовательно, **более близкий истинный CATE соседей сам по себе не гарантирует меньшую ошибку CausalPFN**. По Q̂ и regret@10% при входе из 32 признаков устойчивого преимущества feature32 над feature8 нет. Данные одной генеративной схемы и последующий анализ не доказывают общего механизма.

На входе из 8 признаков feature8 всё же улучшил CATE RMSE против query-dependent random на `0.01989` в среднем, 10/10 seeds, и regret@10% на `1.80` процентного пункта, 10/10. При входе из 32 признаков абсолютные ошибки всех методов значительно выше; это отдельное влияние шумовых столбцов на FM, не эффект селектора.

Этот эксперимент объясняет возможную границу применения CS01. Он не служит подтверждением общего прироста на реальных датасетах.

[E02/v001](experiments/E02/v001.md) заранее зафиксировал тест на новых seeds `71–80`: оставляя вход CausalPFN неизменным, заменить половину ближайших по 8 признакам соседей случайными train-строками в каждом treatment arm. [Снимок результата](results/E02/v001/20261019T075237_942688Z/README.md): primary `RMSE(local8) − RMSE(mix50) = −0.00107` в среднем, положителен в 4/10 seeds; bootstrap-интервал по generated seeds `[−0.00338; +0.00089]`, sign-test `p=0.754`. Заранее заданный ориентир **не выполнен**. При этом `RMSE(random) − RMSE(mix50) = +0.01017` и положителен в 10/10 seeds: некоторая локальность помогает в этом DGP, но случайная половина контекста не улучшила полностью локальный вариант. `feature32` всё ещё лучше `mix50` по CATE RMSE в 9/10 seeds (средняя разность `RMSE(feature32) − RMSE(mix50) = −0.00964`). Поэтому E01-эффект нельзя объяснить просто добавлением случайного разнообразия; механизм остаётся открытым. По Q̂ и regret@10% направление между `local8` и `mix50` неустойчиво. Все 40 предсказаний, парность, контексты, RMSE, regret, Q̂ и SHA проверены независимо; результат касается одного DGP.

[E03/v001](experiments/E03/v001.md) — отдельный **ретроспективный** анализ сохранённых E01 контекстов: прямое локальное среднее uplift против CausalPFN. [Снимок результата](results/E03/v001/20261019T081002_608943Z/README.md) показывает разворот эффекта контекста: `RMSE(feature32) − RMSE(feature8)` равно `+0.01462` для прямого локального среднего, но `−0.01251` для FM; взаимодействие `−0.02713`, одного знака в 10/10 seeds. Контраст выбран после просмотра E01, поэтому не является новым подтверждающим экспериментом. Абсолютная CATE RMSE простого локального среднего **ниже** FM для обоих селекторов на этом DGP; это не поддерживает тезис об универсальной добавочной ценности FM. Условный интервал взаимодействия по десяти seeds `[−0.03073; −0.02350]` относится только к данному DGP и не исправляет post-hoc выбор анализа.

[E04/v001](experiments/E04/v001.md) заранее задал на новых seeds `81–90` контраст близких и далёких по 24 нерелевантным координатам контекстов при почти одинаковой близости по 8 полезным признакам. [Снимок результата](results/E04/v001/20261019T115526_827302Z/README.md): `RMSE(PFN far_noise) − RMSE(PFN near_noise) = −0.00927`, отрицателен в 10/10 seeds; 95% bootstrap-интервал по seeds `[−0.01157; −0.00695]`, двусторонний sign-test `p=0.00195`. Предзаданный ориентир в пользу **близкого по шуму** контекста не выполнен. Разность полезной дистанции между методами всего `+0.00005`, тогда как шумовая дистанция у `far_noise` выше на `1.956`; разность истинного CATE соседей почти нулевая (`+0.00001`). Прямое локальное среднее на тех же соседях меняет RMSE лишь на `−0.00023` в среднем, а взаимодействие FM минус локальное среднее равно `−0.00904`. Это поддерживает **чувствительность FM к распределению нерелевантных входных признаков** в данном DGP, причём направление противоположно исходному объяснению E01 через близость в полном входе. Вторичные Q̂ (`+0.00914`, 5/10 положительных), regret@10% и uplift@10% не показывают устойчивого выигрыша; абсолютная CATE RMSE локального среднего остаётся ниже FM. Все 10 генераций, 40 предсказаний, 20 контекстов, метрики, bootstrap и SHA проверены независимо. Данные всё ещё происходят из одного DGP, поэтому механизм нуждается в отдельной проверке на новой генеративной схеме и целевой метрике uplift.
