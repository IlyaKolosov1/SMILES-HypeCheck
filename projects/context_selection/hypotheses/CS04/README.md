# CS04 — когда локальный контекст перестаёт помогать

**Вопрос:** зависит ли выигрыш treatment-balanced feature-kNN контекста для CausalPFN от того, насколько расстояние в признаках отражает близость истинного эффекта лечения?

Статус: **план**. [E01/v001](experiments/E01/v001.md) задаёт синтетическую проверку с известным CATE: к той же задаче добавляются нерелевантные признаки, а исходы и treatment остаются идентичными внутри парного seed. Основной показатель — изменение преимущества feature-контекста перед query-dependent random по CATE RMSE. Метрики таргетинга и качество соседей анализируются отдельно.

Этот эксперимент объясняет возможную границу применения CS01. Он не служит подтверждением общего прироста на реальных датасетах.
