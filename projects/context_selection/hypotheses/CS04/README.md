# CS04 — когда локальный контекст перестаёт помогать

**Вопрос:** зависит ли выигрыш treatment-balanced feature-kNN контекста для CausalPFN от того, насколько расстояние в признаках отражает близость истинного эффекта лечения?

Статус: **план**. [E01/v001](experiments/E01/v001.md) задаёт синтетическую проверку с известным CATE: к той же задаче добавляются нерелевантные признаки, а исходы и treatment остаются идентичными внутри парного seed. Основной показатель — изменение CATE RMSE при выборе соседей по 8 полезным или по всем 32 признакам **при одном входе FM из 32 признаков**. Метрики таргетинга и качество соседей анализируются отдельно.

Этот эксперимент объясняет возможную границу применения CS01. Он не служит подтверждением общего прироста на реальных датасетах.
