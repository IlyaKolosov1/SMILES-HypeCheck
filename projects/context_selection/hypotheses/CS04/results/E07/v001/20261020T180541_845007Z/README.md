## Что показал заранее заданный тест

Первый, train-only gate прошёл: input top-8 нашёл 8/8 полезных признаков во всех восьми генерациях; retrieval top-4 нашёл минимум 3/4 модификатора эффекта в 6/8. Поэтому FM-инференс был запущен по протоколу. Для основного метода `D=split4_input8` четыре условия дали:

| Парная разность | Среднее | Положительных seeds | Условие |
| --- | ---: | ---: | --- |
| PEHE(`full_full`) − PEHE(D) | +0.08239 | 8/8 | выполнено |
| PEHE(`shared8_input8`) − PEHE(D) | **−0.00028** | **5/8** | **не выполнено** |
| PEHE(`global_T_input8`) − PEHE(D) | +0.05583 | 8/8 | выполнено |
| Regret@10%(`global_T_input8`) − Regret@10%(D) | +0.02016 | 7/8 | выполнено |

Средняя PEHE `full_full` 0.21363, `full_input8` 0.15315, `shared8_input8` **0.13096**, D 0.13124. Значит, большой выигрыш относительно полного FM возник главным образом от **удаления шумовых входов** (+0.06048 PEHE) и использования выбранных признаков в retrieval; **отдельный effect-only retrieval дополнительного выигрыша не показал**. Условный bootstrap-интервал по восьми генерациям для `shared−split`: [−0.00789; +0.00737]. Это не тест эквивалентности.

Сильнее всех по абсолютной PEHE оказался **прямой local** на тех же `split4` соседях: 0.12035 против 0.13124 у FM, разность `local−FM=−0.01089` во всех 8/8. Его средний regret@10% также ниже: 0.07365 против 0.08651. Даже oracle-вариант FM с истинными четырьмя retrieval и восемью input признаками имеет PEHE 0.12355 и regret 0.07452; он не доказывает преимущество FM над простым local. Глобальные T-Learner уступили D, но это не отменяет провал заранее заданного сравнения с общим набором признаков и direct local.

**Решение:** не объявлять раздельные feature spaces методом для short paper на основании E07 и не подбирать новые веса importance или seeds по этим eval. Результат уточняет границу FM: train-only сокращение входа помогает на этой схеме, но модельный слой не превзошёл более простой оцениватель на том же effect-контексте. Требуется независимая научная идея или новый внешний контраст, а не ещё одна абляция той же DGP.

Проверены все 8 generated datasets, 64 файла предсказаний, 32 контекста с 256 строками каждого treatment arm, парные разности, bootstrap и SHA локальных/компактных файлов. Полный расчёт занял 2739.8 с (45.7 мин), локальный вывод 145 MB; пик RAM не измерен. Bootstrap-интервалы условны на этом DGP и не являются статистическим доказательством на реальных популяциях.
