# CS02 / E03 / v002 — завершённый sweep трёх размеров

После неполного v001 область запуска ограничена `K=512,1024,2048` на одном Hillstrom split (`visit`). Для каждого K сравниваются одинаковые методы и eval-объекты; primary — paired normalized Qini AUC, вторичные uplift@10% и runtime. Это **разведочная** проверка чувствительности к K, без независимых выборок.
