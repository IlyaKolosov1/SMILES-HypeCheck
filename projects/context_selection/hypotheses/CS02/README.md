# CS02 — устойчивость выбора контекста на Hillstrom

**Вопрос:** как меняются оценки selector при новом split seed и размере контекста на Hillstrom (`visit`, any email против no email)? Основной ориентир — paired разность normalized Qini AUC при равных eval-строках и `K`; также сохраняются uplift@10% и время. Эти прогоны локальные и разведочные, они не заменяют cross-dataset CS01.

| Эксперимент | Версии | Результаты |
| --- | --- | --- |
| E01 — первый fixed-K пилот | [v001](experiments/E01/v001.md) | [3 запуска](results/E01/v001/), два неполных и один полный |
| E02 — повторение по seeds | [v001](experiments/E02/v001.md) | [5 завершённых запусков](results/E02/v001/) |
| E03 — sweep размера контекста | [v001](experiments/E03/v001.md), [v002](experiments/E03/v002.md) | [v001 неполный](results/E03/v001/), [v002 завершённый](results/E03/v002/) |

Код — [pilot.py](../../src/pilot.py). Исторические конфигурации и таблицы лежат внутри результатов; исходные предсказания и индексы контекста остаются в `artifacts/local/`. Ни один результат здесь не доказывает универсальное улучшение FM.

Короткая проверка из корня репозитория с локально доступным checkpoint:

```bash
.venv/bin/python projects/context_selection/src/pilot.py --device cpu --context-sizes 16 --revision 83aad07da1cb077cfda4236878a1b07dc9f72a54
```

Без `--run` метрики не вычисляются; полный запуск описывается отдельной версией протокола.
