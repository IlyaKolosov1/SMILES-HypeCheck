# CS05 / E01 / v001 — свежая проверка локального feature-retrieval

- **Статус:** plan. Код и протокол зафиксировать Git-коммитом до чтения `visit` новых когорт. Owner: участники CS05; независимая проверка результата ожидается. Вопрос выбран после M01/E08–E09: положительный результат останется новым тестом на не просмотренных строках Criteo, а не независимым выбором датасета или comparator.
- **Данные:** Criteo-ITE-v2.1, benefit outcome `visit`, прежние десять `f*` признаков и закреплённые SHA исходных parquet/metadata. Проверить неизменяемые M01/E06 и E08 снимки и сохранённые source-row IDs. Исключить все sample seeds `42,301–303,401–409`. Из остальных строк последовательно, без замены выбрать три непересекающиеся выборки по 200 000 строк с seeds `410,411,412`; split seeds соответственно `120,121,122`. `--check` сверяет эти ID/SHA и локальные входы, не читая `visit` новых строк.
- **Разбиение:** один group-safe split по одинаковым векторам признаков внутри выборки; ровно 51 200 train и 32 768 eval строк в каждой когорте. Один и тот же train/eval, treatment и outcome для всех методов. Преобразование признаков обучать только на train. При несоответствии исходных меток, пустой ячейке `T × visit` или утечке группы запуск пометить `incomplete`, seed не заменять.
- **Методы:** query-dependent feature-kNN в пространстве прежнего train-only standard-scaled preprocessing; 256 ближайших control + 256 ближайших treated соседей на каждый eval-запрос. Три query-dependent random-контекста с seeds `211,212,213`, те же `K=512` и баланс 256/256. Score каждого селектора — `mean(train visit | treated, context) − mean(train visit | control, context)`. Фиксированный S-Learner из `m01_e02.fit_predict` на том же train, параметры `HistGradientBoosting` из M01/E08: `learning_rate=0.05`, `max_iter=200`, `max_leaf_nodes=31`, `l2_regularization=1.0`, seed `42`; T/X — дополнительные ориентиры. Не подбирать параметры или бюджет по eval. CausalPFN не запускать: здесь проверяется необходимый baseline для интерпретации его результатов.
- **Primary:** Q̂ (`normalized_qini_auc` из `qini_auc_score`). В каждой когорте вычислить две парные разности: `local feature − mean(Q̂ local random seeds)` и `local feature − S-Learner`. Среднее random берётся **по метрикам**, context seeds не считаются независимыми повторами. Главная сводка — равновесное среднее трёх cohort-разностей. Совместный **описательный ориентир** выполнен, если обе средние положительны, обе разности положительны в 3/3 когортах и нижние границы 95% условного bootstrap-интервала средних > 0. Если S выигрывает, нельзя утверждать полезность локального селектора сверх сильного классического baseline.
- **Неопределённость:** 500 парных bootstrap-повторов eval-строк внутри treatment arms для каждой когорты с фиксированными score, seeds `10000+sample_seed`. Те же ресэмплированные строки для всех методов. Для среднего трёх когорт соединить draws по номеру и взять percentile 95% интервал. Интервалы условны на этих train/eval, обученных моделях и выборе Criteo после старых результатов; три когорты из одного исходного набора не дают междатасетного p-value.
- **Secondary:** Q̂ локального метода против T/X, normalized AUUC, uplift@10% с фиксированным hash-порядком ties по `source_row` из M01/E08, время отбора и обучения. Выбор primary по вторичным метрикам запрещён.
- **Хранение:** полные score, IDs и контексты — в `artifacts/local/cs05_e01_results/`, отдельная папка на когорту, статус `incomplete` при сбое. После трёх завершений — один компактный неизменяемый снимок `results/E01/v001/<run-id>/` с протоколом, метриками, разностями, 95% условными интервалами, SHA входов и локальных выходов, Git SHA и SHA кода. Старые снимки не менять.

Перед расчётом выполнить `.venv/bin/python tools/run_cs05_e01.py --help`, `--check`, smoke локальных score/разрешения ties, валидатор и Git-коммит кода/протокола. Затем `.venv/bin/python -u tools/run_cs05_e01.py all`. Полный FM-инференс не требуется. После расчёта независимо проверить исходные метки, разбиения, контексты, score, метрики и bootstrap.
