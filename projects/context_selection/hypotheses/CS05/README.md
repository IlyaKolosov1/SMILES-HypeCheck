# CS05 — ценность retrieval без FM-инференса

**Вопрос:** даёт ли treatment-balanced feature-kNN по `K=512` полезное ранжирование uplift самим прямым средним исходов по соседям, превосходя не только случайный контекст, но и фиксированную классическую модель на новых данных?

**Основной контраст:** Q̂ (`normalized_qini_auc`) локального feature-kNN минус средняя Q̂ трёх query-dependent random-контекстов и минус Q̂ S-Learner на одинаковых eval-строках. Выбор S-Learner как сильного baseline сделан после M01/E08, а сам вопрос — после ретроспективного M01/E09; поэтому новый тест не делает прежние анализы подтверждающими.

**Статус:** [E01/v001](experiments/E01/v001.md) — plan, три новые непересекающиеся Criteo-выборки `410–412`; результатов пока нет. Код, локальные полные выходы и неизменяемый снимок будут привязаны к протоколу и SHA. Даже положительный итог касается одного исходного RCT-набора с неизвестными ID рекламодателей. Гипотеза не утверждает преимущество самого CausalPFN.
