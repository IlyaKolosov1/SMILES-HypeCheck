# CS05 — ценность retrieval без FM-инференса

**Вопрос:** даёт ли treatment-balanced feature-kNN по `K=512` полезное ранжирование uplift самим прямым средним исходов по соседям, превосходя не только случайный контекст, но и фиксированную классическую модель на новых данных?

**Основной контраст:** Q̂ (`normalized_qini_auc`) локального feature-kNN минус средняя Q̂ трёх query-dependent random-контекстов и минус Q̂ S-Learner на одинаковых eval-строках. Выбор S-Learner как сильного baseline сделан после M01/E08, а сам вопрос — после ретроспективного M01/E09; поэтому новый тест не делает прежние анализы подтверждающими.

**Статус:** [E01/v001](experiments/E01/v001.md) завершён как разведочная проверка трёх новых непересекающихся Criteo-выборок `410–412`. [Неизменяемый снимок](results/E01/v001/20261019T172329_275728Z/README.md): локальный feature-контекст превосходит среднее трёх random-context seeds по Q̂ на `+0.0783` в среднем, 3/3 когорты положительны, условный 95% интервал `[+0.0382; +0.1142]`. Против фиксированного S-Learner средняя разность `−0.0019`, положительна в 2/3, интервал `[−0.0337; +0.0296]`. **Совместный заранее заданный ориентир не выполнен.** Вторичный uplift@10% не даёт устойчивого преимущества локального метода над S (1/3 когорт положительна).

Проверены SHA 12 файлов снимка и 51 локального файла, исходные `T/visit`, group-safe split, по 32 768 сбалансированных контекстов для каждого из четырёх селекторов в каждой когорте, локальные score, Q̂/AUUC/uplift@10% и 500 парных bootstrap-повторов в каждой когорте. Это подтверждает ценность выбора контекста против random **в данной постановке**, но не превосходство над сильным классическим baseline, не FM-эффект и не переносимость на другие датасеты. Все когорты происходят из одного Criteo-источника с недоступными ID рекламодателей; интервалы условны на обучении и выбранном датасете.
