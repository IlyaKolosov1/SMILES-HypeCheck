# Q̂: один context seed на пяти folds

**Статус:** `complete_exploratory`. Это повторный анализ сохранённых предсказаний [v003](../../v003/20261013T202852_574199Z/README.md), выполненный по [протоколу v004](../../../../experiments/E01/v004.md). CausalPFN повторно не запускался. Q̂ численно совпадает с прежней `normalized_qini_auc`; изменился baseline: `random_query_s42` вместо среднего seeds `42,43,44`.

Средняя парная разность Q̂ по пяти outer folds (`селектор − random_query_s42`); в скобках число положительных folds:

| Датасет | Feature-kNN | Effect-kNN |
| --- | ---: | ---: |
| Hillstrom | +0.0224 (4/5) | +0.0070 (3/5) |
| Retailhero-uplift | +0.0127 (4/5) | +0.0146 (4/5) |
| LZD | +0.0729 (5/5) | +0.0225 (4/5) |
| Criteo-ITE-v2.1 | +0.0626 (3/5) | −0.0132 (2/5) |

Все 60 значений Q̂ пересчитаны из исходных `predictions.csv` и совпали с v003 в пределах `1e-10`. Для 40 парных разностей получено по 500 корректных bootstrap выборок. [Полная таблица по fold](all_paired_deltas.csv) содержит условные 95% интервалы; [сводка](selector_effects_summary.csv) показывает среднее и диапазон между folds. [Протокол](protocol.json) содержит Git SHA аналитического кода и SHA исходного v003 manifest; [контрольные суммы](source_files.csv) перечисляют 60 локальных исходных CSV. Большие предсказания остаются в исключённом из Git `artifacts/local/`.

**Ограничение:** пять folds имеют пересекающиеся train banks, а Criteo использует один 100k source sample. Bootstrap условен на уже обученных моделях и выбранных контекстах; один seed `42` не оценивает чувствительность к случайному контексту. Знак разности `effect_knn` на Criteo отличается от сравнения со средним трёх seeds в v003, поэтому положительный общий вывод по этому селектору здесь делать нельзя. Статистическая значимость общего улучшения не установлена.
