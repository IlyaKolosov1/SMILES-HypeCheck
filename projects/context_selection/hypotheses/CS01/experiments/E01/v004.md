# CS01 / E01 / v004 — Q̂ при одном context seed

- **Статус:** разведочный повторный анализ сохранённых предсказаний [v003](v003.md), без нового обучения или инференса CausalPFN. Исходный запуск: `20261013T202852_574199Z`.
- **Вопрос:** сохраняются ли знаки и величины парных эффектов селекторов, если вместо среднего трёх `random_query` seeds взять только seed `42`?
- **Primary контрасты:** `feature_knn − random_query_s42` и `effect_knn − random_query_s42` внутри каждого датасета и outer fold при `K=512`. Метрика Q̂ — нормированный коэффициент Qini: `(AUQC_model − AUQC_random) / (AUQC_max − AUQC_random)`. Это та же `normalized_qini_auc` из v003, вычисленная `sklift.metrics.qini_auc_score(..., negative_effect=True)`; `AUQC_max` строится по наблюдаемым treatment/outcome, а не по истинным индивидуальным эффектам.
- **Данные и методы:** сохранённые `predictions.csv` для Hillstrom (`visit`), Retailhero-uplift (`Y`), LZD (`Y`) и Criteo-ITE-v2.1 (`visit`), folds `0…4`, один Criteo source sample 100 000, train max 51 200, eval max 4096. Outer split seed `42`, context seed `42`, пять inner folds для исходного cross-fit, checkpoint `83aad07da1cb077cfda4236878a1b07dc9f72a54`. Предсказания селекторов и baseline берутся из одного fold и одних eval-строк.
- **Неопределённость:** 500 парных bootstrap выборок eval-строк внутри treatment arm для каждого fold, seed `42 + fold + 999`; 95% percentile интервал считается только при ≥400 корректных выборках. Интервалы условны на сохранённых моделях, контекстах и eval-наборе. Усреднение по пяти folds описательное: их train banks перекрываются, поэтому p-value и claim о статистической значимости не рассчитываются. Два селектора и четыре датасета не объединяются в один подтверждающий тест.
- **Воспроизводимость:** [скрипт повторного анализа](../../../../src/reanalyse_qini_single_seed.py) проверяет исходный v003 `manifest.json`, все 20 пар `predictions.csv`/`metrics.csv`, eval IDs и совпадение Q̂ с записанной метрикой. SHA исходных файлов, SHA скрипта и его Git commit записываются в новом `protocol.json`; полный вывод создаётся в `artifacts/local/qhat_reanalysis_results/`.
- **Ожидаемый снимок:** `all_metrics.csv`, `all_paired_deltas.csv`, `selector_effects_summary.csv`, `source_files.csv`, `protocol.json`, `README.md`, `manifest.json` в `results/E01/v004/<run-id>/`. Старый v003 остаётся неизменным.
