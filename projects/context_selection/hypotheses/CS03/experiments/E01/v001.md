# CS03 / E01 / v001 — synthetic noisy retrieval

Пять независимо сгенерированных наборов (seeds `42–46`), DGP `three_groups_v1`, train 8192, eval 4096, `K=512`. Сравниваются oracle, noisy effect-score selectors и смешанный контекст. Primary: CATE RMSE и regret@10%; Qini вторична. Oracle — привилегированная диагностика, не применимая модель для реальных данных.

Статус: **завершённый exploratory run**. Один context seed на сгенерированный набор; условные и непоправленные интервалы не подтверждают переносимость. [Конфигурация, общие таблицы и метрики пяти seeds](../../results/E01/v001/20261007T062843_026698Z/).
