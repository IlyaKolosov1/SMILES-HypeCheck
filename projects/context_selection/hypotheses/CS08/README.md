# CS08 — сопоставимость treatment-групп внутри контекста

**Вопрос:** остаётся ли в уже выбранных `feature_knn_K512` контекстах существенная
разница исходного прогноза между treated и control, хотя число строк в группах
равно? Такой перекос мог бы мотивировать парный селектор, который одновременно
сохраняет близость к запросу.

**Статус:** [E01/v001](experiments/E01/v001.md) завершён как разведочная
диагностика сохранённых контекстов CS01/E02 без FM-инференса.
[Снимок результата](results/E01/v001/20261029T203405_436715Z/README.md):
предзаданный gate **не пройден** — только Criteo из необходимых двух датасетов
имел средний абсолютный разрыв исходного прогноза ≥0,5 п.п. при положительном
OOF Brier skill во всех трёх разбиениях. Средние разрывы feature-kNN:
Hillstrom `0,469`, RetailHero `0,182`, LZD `0,177`, Criteo `1,090` п.п.
На RetailHero и LZD они даже меньше, чем у случайного контекста. Поэтому
общий парный селектор по этому `g0` **не получает основания для FM-запуска**.

**Граница вывода:** разность прогнозов — измеримый признак состава контекста,
но не истинное смещение CausalPFN. Новые разбиения того же источника не являются
новыми независимыми кампаниями. Следующий FM-эксперимент допустим лишь после
анализа диагностики и отдельного протокола с `uplift@10%` как primary.
