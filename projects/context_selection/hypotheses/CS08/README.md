# CS08 — сопоставимость treatment-групп внутри контекста

**Вопрос:** остаётся ли в уже выбранных `feature_knn_K512` контекстах существенная
разница исходного прогноза между treated и control, хотя число строк в группах
равно? Такой перекос мог бы мотивировать парный селектор, который одновременно
сохраняет близость к запросу.

**Статус:** [E01/v001](experiments/E01/v001.md) — заранее заданная дешёвая
диагностика сохранённых контекстов CS01/E02. Она не запускает CausalPFN и не
проверяет качество нового селектора по `uplift@10%`. Результат будет добавлен
после расчёта.

**Граница вывода:** разность прогнозов — измеримый признак состава контекста,
но не истинное смещение CausalPFN. Новые разбиения того же источника не являются
новыми независимыми кампаниями. Следующий FM-эксперимент допустим лишь после
анализа диагностики и отдельного протокола с `uplift@10%` как primary.
