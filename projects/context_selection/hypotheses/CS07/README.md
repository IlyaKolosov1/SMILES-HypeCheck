# CS07 — сохранять оба потенциальных исхода при поиске контекста

**Вопрос:** помогает ли causal FM контекст, выбранный по двум слабым прогнозам потенциальных исходов, сильнее контекста, выбранного только по их разности?

**Основание:** CausalPFN оценивает `mu0(x)` и `mu1(x)` по отдельности, а описанная авторами эвристика для больших таблиц упорядочивает примеры по `tau_hat=mu1_hat−mu0_hat`. Разность не сохраняет уровень исходов. [Литературный разбор и границы новизны](../../../../docs/LITERATURE_POSITIONING.md).

**Основной контраст:** изменение преимущества двумерного CEPO-контекста над effect-score-контекстом при контролируемом увеличении вариации базового риска. Во всех условиях одинаковы исходные X/T, истинный CATE, шумовые uniform-числа, слабая модель, бюджет и treatment-баланс. Прямое локальное среднее по тем же соседям показывает, какая часть эффекта принадлежит самому retrieval.

**Статус:** [E01/v001](experiments/E01/v001.md) — протокол контролируемой проверки, результаты ещё не получены. Это screening механизма; внешнее подтверждение на RCT понадобится отдельно.
