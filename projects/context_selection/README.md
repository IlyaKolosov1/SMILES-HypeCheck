# Проект: выбор контекста

Проверяем, как состав контекста CausalPFN влияет на uplift при одинаковом бюджете `K` и тех же eval-объектах. В таблицах разделяем эффект selector, качество вспомогательной модели и разброс между датасетами.

| Гипотеза | Эксперименты и статус |
| --- | --- |
| [CS01: selector против random](hypotheses/CS01/README.md) | E01/E02: cross-dataset проверки; E03: новые Criteo-выборки; E04/E05: новые LZD holdout и отдельные train banks; сигнал положительный и разведочный |
| [CS02: устойчивость на Hillstrom](hypotheses/CS02/README.md) | Локальный пилот, пять seeds и sweep размера контекста; есть неполные запуски |
| [CS03: качество effect-score selector](hypotheses/CS03/README.md) | Две синтетические серии с известным CATE; разведочные результаты |
| [CS04: лишние признаки и локальность](hypotheses/CS04/README.md) | E01 завершён: поиск по шумным признакам неожиданно снизил CATE RMSE при фиксированном входе FM; проверяем роль разнообразия контекста |
| [CS05: retrieval без FM-инференса](hypotheses/CS05/README.md) | E01: на новых Criteo-строках local feature > random по Q̂ в 3/3, но не превосходит устойчиво S-Learner; разведочный результат |
| [CS06: доля treatment arms в контексте](hypotheses/CS06/README.md) | E01: три новые Criteo-когорты; interaction FM−local при смене доли arms неустойчив, ориентир не выполнен; v002 сохраняет точные score |
| [CS07: оба потенциальных исхода в контексте](hypotheses/CS07/README.md) | E01: контролируемая проверка CEPO-пары против слабого effect-score; протокол, без результатов |
