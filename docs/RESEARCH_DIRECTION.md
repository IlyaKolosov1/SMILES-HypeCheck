# Текущее направление исследования

## Рабочая гипотеза

При ограниченном бюджете контекста CausalPFN может лучше ранжировать индивидуальный uplift, если для каждого запроса брать близкие по признакам train-примеры **отдельно в treatment и control arms**. Модель должна давать ценность сверх простого локального среднего исходов по тем же соседям. Ожидаемый эффект **условен на задаче**; универсального выигрыша над классическими uplift-моделями мы не предполагаем.

| Проверка | Главный парный контраст Q̂ | Наблюдение |
| --- | --- | --- |
| [CS01/E03: новые Criteo строки](../projects/context_selection/hypotheses/CS01/experiments/E03/v001.md) | Feature-контекст − среднее random | `+0.1094`, 3/3 выборки положительны |
| [CS01/E04: новый LZD holdout](../projects/context_selection/hypotheses/CS01/experiments/E04/v001.md) | Feature-контекст − среднее random | `+0.0859`, 3/3 блока положительны; один общий train bank |
| [CS01/E05: отдельные LZD train banks](../projects/context_selection/hypotheses/CS01/experiments/E05/v001.md) | Feature-контекст − среднее random | `+0.0611`, 3/3 когорты положительны; новые context seeds |
| [M01/E03: те же LZD соседи](../projects/model_comparison/hypotheses/M01/experiments/E03/v001.md) | CausalPFN − прямой локальный uplift | `+0.0481`, 3/3 когорты положительны |
| [M01/E04: те же Criteo соседи](../projects/model_comparison/hypotheses/M01/experiments/E04/v001.md) | CausalPFN − прямой локальный uplift | `+0.0755`, 3/3 когорты положительны; все условные интервалы пересекают ноль |
| [CS03/E01: синтетика с известным CATE](../projects/context_selection/hypotheses/CS03/experiments/E01/v001.md) | Feature-контекст − random | Qini `+0.0135` и CATE RMSE `−0.0247`, оба 5/5 по нужному направлению; regret@10% улучшился 3/5 |
| [M03/E02: фиксированная смесь](../projects/model_comparison/hypotheses/M03/experiments/E02/v001.md) | Interaction контекста и смеси с X-Learner | `−0.0441` в среднем; смесь не дала устойчивого выигрыша сверх feature-контекста |
| [CS04/E01: контрольная синтетика](../projects/context_selection/hypotheses/CS04/experiments/E01/v001.md) | RMSE поиска по 32 − поиска по 8 полезным признакам при одинаковом входе FM | `−0.01251`, 0/10 положительных: исходная гипотеза о вреде шумового поиска опровергнута в этом DGP |
| [CS04/E03: post-hoc model × context](../projects/context_selection/hypotheses/CS04/experiments/E03/v001.md) | Эффект feature32 − feature8 у FM минус тот же эффект у прямого локального среднего | `−0.02713`, 10/10 одного направления; локальное среднее имеет меньшую абсолютную CATE RMSE на этом DGP |

Это **разведочные результаты**. Criteo и LZD выбраны после более ранних экспериментов; LZD когорты используют один исходный RCT-датасет, а старые CS03 проверки — один DGP и общий случайный контекст для всех запросов вместо query-dependent random в реальных CS01/E03–E05. Новая CS04 синтетика использует query-dependent random, но также только один DGP. Bootstrap-интервалы условны на выбранных строках и обучении; CS04/E03 выбран post-hoc. На LZD `feature_knn` не превосходит фиксированные S/T/X-Learner устойчиво по когортам, на Hillstrom направление эффекта выбора контекста ранее было отрицательным, а на CS04 прямое локальное среднее превосходит FM по абсолютной CATE RMSE. Поэтому формулировка «лучше всех моделей на всех датасетах» не поддерживается.

## Что здесь может стать вкладом работы

Идея kNN-контекста для табличных FM уже есть в [LoCalPFN](https://arxiv.org/abs/2406.05207); авторы [CausalPFN](https://arxiv.org/abs/2506.07918) тоже описывают retrieval для больших таблиц, используя слабую оценку CATE. Наш потенциальный вклад — **какой контекст нужен именно для uplift-задачи**, как его выбирать при балансе treatment arms и когда отбор улучшает либо ухудшает Q̂ и качество таргетинга. Эмпирического сравнения двух простых селекторов недостаточно для заявления о новом методе; нужно объяснить механизм и проверить границы применимости.

## Ближайшие проверки

1. Выполнить [CS04/E02](../projects/context_selection/hypotheses/CS04/experiments/E02/v001.md): более близкие по истинному CATE соседи в E01 дали **худшую** CATE RMSE FM при входе из 32 признаков. Контролируемо разбавить слишком локальный контекст случайными train-строками при неизменных `K`, labels и входе модели, на новых генерациях. Это проверит, помогает ли разнообразие контекста, а не просто изменение способа измерения расстояния.
2. Для подтверждающего утверждения заранее выбрать новый независимый RCT-источник и primary контраст до просмотра его результатов. Нынешние LZD/Criteo проверки и один синтетический DGP не заменяют такую валидацию.

Аудит нового кандидата приведён в [EXTERNAL_DATA_AUDIT.md](EXTERNAL_DATA_AUDIT.md): Udacity/Starbucks пригоден для заранее заданного внешнего теста, хотя редкий `purchase` ограничит точность. Lenta пока нельзя считать подтверждающим RCT из-за неустановленного механизма назначения и заметного дисбаланса исторического `response_sms`.

Существующая [CS03/E02 диагностика](../projects/context_selection/hypotheses/CS03/README.md) уточняет пункт 2: effect-score retrieval чуть снижал среднюю дистанцию до истинного CATE соседей, но давал худший CATE RMSE CausalPFN, хотя Qini была немного выше. Эти pipelines имеют разный доступ к labels, поэтому следующий синтетический тест должен фиксировать **не только `K`, но и весь доступный train budget**. Иначе разницу нельзя приписать выбору контекста.
