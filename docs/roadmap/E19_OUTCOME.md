# E19/v002: один локальный сигнал при K512, общего преимущества FM нет

**28 октября 2026. Статус:** [протокол](../../projects/model_comparison/hypotheses/M01/experiments/E19/v002.md) исполнен на Linux/CUDA (RTX 2080 Ti, PyTorch 2.3.1+cu121); [неизменяемый компактный снимок](../../projects/model_comparison/hypotheses/M01/results/E19/v002/20261027T102805_054844Z/README.md) имеет статус `complete_exploratory`. Четыре ранее изученных источника, по одному фиксированному split, `N={8192,51200}` × `K={512,2048}`. Основная метрика — `uplift@10%`, основной контроль — фиксированный S-Learner; Q̂ и matched-local — дополнительные проверки.

## Что получилось

| LZD, N=51 200, K=512 | Uplift@10%, п.п. | Q̂ |
| --- | ---: | ---: |
| CausalPFN + feature-kNN | 2,363 | 0,02725 |
| S-Learner | 0,934 | −0,00361 |
| Direct local на тех же соседях | 0,821 | 0,00413 |

Парная разность **FM−S = +1,429 п.п.**, условный 95% bootstrap-интервал `[+0,276; +2,453]`; **FM−local = +1,542 п.п.** `[+0,659; +2,418]`. Оба номинальных интервала положительны, а сравнение с local отделяет этот сигнал от эффекта одного только поиска соседей. Для остальных **15 из 16** ячеек FM−S и **15 из 16** FM−local интервалы включают ноль. На Criteo при `N=8192` обе точечные FM−S разности отрицательны. Увеличение K с 512 до 2048 на LZD при `N=51200` изменило FM uplift на `−0,717` п.п. с интервалом `[−1,573; +0,169]`; монотонный выигрыш от большего контекста не установлен.

Для LZD `N=51200` время полной FM-ячейки — ~17,0 мин при K512 и ~76,3 мин при K2048. Сумма времени 16 FM-ячеек — ~9,54 ч; совместный fit/predict S/T/X по восьми dataset×N — 26,4 с. Это разные объёмы работ, поэтому их отношение не является честным единым коэффициентом ускорения модели. Основная стоимость FM — forward (~9,01 ч), retrieval ~13,6 мин.

## Что проверено и чего ещё нет

- SHA256 всех 11 файлов компактного снимка совпали с manifest; SHA runner, протокола и трёх зависимостей — с зафиксированным кодом commit `1584d618a1c118a53659d8319d74cb109c0e47f4`.
- 12/12 SHA исходных parquet/metadata совпали с локальными исходными файлами. Повторное построение split дало те же 8 train-ID и 4 eval-ID SHA и T×Y клетки. Это **другой запуск**, чем отдельный Apple/MPS отчёт на восстановленных публичных данных; его числа нельзя смешивать с CUDA-снимком.
- Снимок содержит 56 строк абсолютных метрик, 92 парных uplift-разности, 92 разности Q̂ и 76 записей времени. 64 простых FM−контроль разности uplift и 64 соответствующие разности Q̂ арифметически совпали с исходными метриками. Все интервалы имеют 500 draws и корректный порядок границ.
- `local_files.csv` перечисляет 102 больших/локальных файла (~7,69 ГБ), включая 4 `predictions.parquet` суммарно ~24 МБ; сами файлы не были переданы. Поэтому индивидуальные предсказания, top-10% маски и bootstrap-интервалы **не пересчитывались независимо**. Для последней проверки достаточно передать хотя бы четыре `predictions.parquet`; для полной сверки SHA локального архива — все перечисленные файлы или проверку на сервере.

**Граница вывода:** положительный интервал для одной из 16 заранее показанных основных ячеек — условный и без поправки на множественные сравнения. Источник LZD уже использовался в исследованиях, split один; эти строки не являются независимой новой кампанией. Это перспективный **разведочный сигнал**, не доказанное общее преимущество CausalPFN и не подтверждающий результат для short paper. Следующее осмысленное действие — сверить показатели с четырьмя файлами предсказаний, затем заранее зафиксировать проверку LZD `N=51200, K=512` на новых eval-группах/внешней RCT, если такие данные доступны. Поиск другого удачного K, seed или метрики после просмотра таблицы не заменяет подтверждение.
